# Book Vibe - Next.js Edition

🚀 **Live Project**: https://next-book-vibe.vercel.app/

A Next.js implementation of the popular Book Vibe project, featuring the same great functionality as the original React version with the power and efficiency of Next.js.

## About This Project

This is a Next.js version of the [original React Book Vibe project](https://github.com/AforArdi/react-book-vibe). I've implemented the same features while leveraging Next.js to create a more performant and scalable application.

## Features

- Browse and discover books
- Add books to your reading list
- Track pages read with interactive charts
- Wishlist functionality
- Responsive design
